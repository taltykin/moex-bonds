итак, для того чтобы установить pandas и другие приложения для этого проекта нам нужно:


1. установить локальное окружение.



 python -m venv env



2. Активируем локальное окружение

python3 env/bin/activate



3.  Теперь устанавливаем необходимые пакеты

pip3 install pandas
 
pip3 install requests

pip3 install openpyxl

все эти приложения установлены локально, т.е. в директории с скриптом. глобально они видны не будут.
